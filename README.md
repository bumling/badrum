# Badrumsunderlag — v34

Öppna Bathroom-handover.html för att se det illustrerade underlaget och rundvandringen.

- Sju PNG-visualiseringar, upp till 1600 × 1200 samt en vy av dörrväggen i 1400 × 1500
- dimensioned-layout.svg: skalbar planritning
- bathroom-walkthrough-full-30s.mp4: 30 sekunder, 1280 × 720, 24 bilder/s
